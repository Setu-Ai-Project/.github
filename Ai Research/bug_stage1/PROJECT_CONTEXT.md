# SetuAI - Bug Mistake Detection, Stage 1 (Step 4)

Goal: find_mistakes(submission, mistakes) warns when a learner's answer contains a known,
human-tagged mistake phrase. STATIC matching only. NO AI calls. Standard library only.

## Rules
- Mistake data lives in a JSON file (id, phrase, variants, explanation, fix_hint).
  Never hard-code phrases in the code.
- Normalize both sides: lowercase, remove punctuation (keep letters of ANY language),
  collapse spaces, ignore apostrophes.
- Whole-word/phrase matching only (word boundaries).
- Negation guard: skip a match if not/never/avoid/without appears just before it.
- Be CAUTIOUS: a false positive is worse than a miss. When unsure, do not match.
- Explanations and hints come from the data file, never generated by AI.
- Never crash on empty text, odd characters or a malformed file; fail quietly (no warning).
- Keep code simple, with beginner-friendly comments.
